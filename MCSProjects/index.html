Projects for MCS Students at UOttawa supervised by Prof. Timothy Lethbridge

I am always interested in taking on 2-4 MCS students in CSI6900 each academic year.

Your task would be to undertake research and development focusing on improving Umple in some way. Contact me via Teams using id tcltcl@uottawa.ca if you are interested.

The main research directions I am working on are:

  • Improving how requirements are represented within Umple so that AIs can use them to generate models and code.
  • Improving the new version of UmpleOnline and experimenting with how it compares to the classic version.
  • Generating new deterministic compilers (using AI) for modern languages like Rust and Go.
  • Exploring how developers can better understand and review code generated by AIs if it is structured as models (in Umple) with embedded code
  • Improving other aspects of the UX of Umple
  • Adding optional plugins to compilers for different frameworks and persistence mechanisms
  • Building demonstration applications in Umple
  • Creating large-scale Umple data models from various sources
  • ... and more

For more information about Umple, see umple.org. For the issue list, see umple.org/issues
